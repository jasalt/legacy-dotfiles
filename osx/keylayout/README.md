Custom "Finnish flavored" US keylayout with additional physical key next to left shift bound to letters ä and ö. Variant for Mac keyboards and Thinkpad X220 / PC keyboard.

# Installation
Copy .keylayout file to `~/Library/Keyboard Layouts/` eg.

cp ISO-US-FIN.keylayout ~/Library/Keyboard\ Layouts/

And add it in Settings>Keyboard>Input Sources, where it's visible under "Others" with name eg. US-FIN.
# Layout Variants

ISO-US-FIN.keylayout is for ISO keyboards and should most probably be selected for EU laptops.

U.S.FIN2019.keylayout is for US macbook keyboard and adds umlaut ao keys to alt+a and alt+o. 


All show up as "U.S. copy" in keyboard settings.
